Painel de edição — Walison Lopes Oficial

Este painel foi incluído para facilitar futuras alterações. Ele funciona no próprio navegador e permite preparar uma versão atualizada do site sem editar código.

Importante: a publicação ao vivo continua dependendo do serviço de hospedagem/GitHub. O painel não altera sozinho o site já publicado.

Informações principais

Fotos adicionais

Escolha fotos novas. O painel cria uma galeria local de pré-visualização. Para colocá-las no site publicado, elas precisam ser enviadas para a hospedagem junto com a versão atualizada.

Salvar

Como usar

  1. Abra este arquivo no computador.
  2. Altere textos, telefones e links.
  3. Adicione as fotos desejadas.
  4. Clique em “Salvar alterações”.
  5. Guarde o backup gerado. Quando a publicação estiver conectada, essas alterações podem ser incorporadas ao site.
